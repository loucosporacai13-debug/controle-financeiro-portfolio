# 💰 Controle Financeiro Pessoal

**Aplicação Web | React + TypeScript | Desenvolvimento assistido por IA**

## 📌 Sobre o projeto

Aplicativo de controle financeiro pessoal criado para organizar informações financeiras em um único ambiente, desenvolvido com apoio do Google AI Studio.

## 🚀 Funcionalidades

O projeto contempla módulos para:

- Dashboard com indicadores financeiros.
- Transações e contas bancárias.
- Movimentações em dinheiro, débito e crédito.
- Investimentos e orçamentos.
- Categorias financeiras.
- Pagamentos recorrentes e lembretes.
- Configurações do aplicativo.

*Os módulos foram identificados no código e ainda precisam de validação funcional para demonstração pública.*

## 🛠️ Tecnologias

React, TypeScript, Vite, Tailwind CSS e Lucide React.

**Ferramenta de desenvolvimento assistido por IA:** Google AI Studio.

## 💾 Armazenamento

O aplicativo utiliza localStorage para salvar e recuperar informações no navegador.

## 📋 Status

Projeto pessoal em desenvolvimento e validação. O código operacional original permanece em repositório privado.
